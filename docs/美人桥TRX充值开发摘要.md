# 美人桥 TRX 充值开发与测试清单摘要

> 详细业务规则与验收口径以本需求 PRD 为准。勾选项全部完成后，方可进入需求验收。

## 开发要做

- [ ] **扩展美人桥默认汇率设置**：在“美人桥业务 → 订单管理”的现有“默认汇率／设置”入口增加 TRX；汇率方向显示为“1 USDT ≈ N TRX”，只允许保存大于 0 的有效数字；USDT 固定为 1，不开放编辑。
- [ ] **隔离汇率来源**：美人桥 TRX 订单只读取美人桥默认汇率，不读取、覆盖或同步蓝盛统一汇率及其他业务汇率；汇率修改沿用现有权限和操作日志规则。
- [ ] **增加商户端 TRX 充值方式**：在“创建充值订单”中增加“TRX充值”；选择后展示 TRX 金额输入、当前兑 U 汇率和预计应上分 U；金额必须大于 0，最多 6 位小数，超过时拒绝提交。
- [ ] **服务端锁定订单汇率并计算上分金额**：提交时重新校验有效汇率，保存充值币种、原始充值金额、本单锁定汇率和应上分 U；计算公式为“TRX 金额 ÷ 本单锁定汇率”，精度与舍入沿用美人桥现有规则；前端预览不得作为最终入账依据。
- [ ] **接入既有 TRX 代收流程**：创建成功后分配 TRX／TRON 地址；复用既有到账确认、过期、无地址、重复通知、订单状态和回调能力，不新增 TRX 专属状态或代付流程。
- [ ] **接入自动与人工上分**：到账后按本单应上分 U 处理；自动上分开启时由系统完成，关闭时进入既有人工处理；两条路径均不得重新读取默认汇率，重复通知或重试不得重复上分。
- [ ] **调整商户端与后台订单列表**：增加 TRX 币种筛选和订单展示；表头统一为“充值金额、充值币种、应上分U、兑U汇率、浮动金额、浮动费率”；每行展示对应订单的原币金额和锁定汇率。
- [ ] **调整汇总、导出与历史兼容**：充值金额按 CNY、USDT、TRX 分币种汇总，应上分 U 单独汇总；导出增加币种、锁定汇率、应上分 U 并使用新表头；历史订单不按当前汇率回填或重算，现有 CNY、USDT 流程保持可用。

## 测试要验

- [ ] **汇率设置与隔离**：TRX 汇率可在美人桥订单管理页保存和读取；空值、非数字、0、负数保存失败且不覆盖原有效值；修改蓝盛其他业务汇率不影响美人桥，反向亦不影响。
- [ ] **创建订单校验**：商户端可选择 TRX；金额大于 0 且不超过 6 位小数时可提交，小于等于 0 或超过 6 位小数时被明确阻止；汇率未设置或失效时不能创建订单。
- [ ] **换算与锁价**：汇率为“1 U ≈ 3.32 TRX”、充值 350 TRX 时，按 `350 ÷ 3.32` 计算并依现有精度得到应上分 U；订单创建后修改默认汇率，原订单结果不变，新订单使用新汇率。
- [ ] **TRX 收款链路**：新订单只能取得 TRX／TRON 地址；到账识别、确认、过期、无地址、晚到账、状态和回调结果符合既有 TRX 代收规则，不出现跨币种地址。
- [ ] **自动与人工上分**：分别在自动上分开启、关闭条件下完成一笔 TRX 订单；两种路径均按订单锁定的应上分 U 更新一次余额，重复通知、重复点击和重试不产生重复上分。
- [ ] **列表、筛选与表头**：商户端和蓝盛后台均可筛选 TRX，并正确显示充值金额、充值币种、兑 U 汇率和应上分 U；后台完整显示新的六个通用表头；重置筛选后恢复全部币种。
- [ ] **汇总与导出**：CNY、USDT、TRX 原币金额分别汇总，不合并成单一金额总计；应上分 U 汇总正确；导出结果与页面查询条件、数据权限、字段名称及金额一致。
- [ ] **回归与异常**：验证历史订单不被新汇率重算，缺少新增字段时按既有空值规则展示；CNY、USDT 的创建、查询、上分和导出均正常；查询、保存、创建或导出失败时均有明确反馈并保留必要操作条件。
