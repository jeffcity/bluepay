# 美人桥 TRX 充值开发与测试清单摘要

> 详细业务规则与验收口径以本需求 PRD 为准。勾选项全部完成后，方可进入需求验收。

## 开发要做

- [ ] **扩展美人桥默认汇率设置**：在“美人桥业务 → 订单管理”的现有“默认汇率／设置”入口，以“币种／汇率／默认”三列表格同时展示 USDT、TRX；分别维护“1 USDT ≈ N CNY”和“1 TRX ≈ N CNY”，每行的“默认”都是独立开关，不互斥。
- [ ] **按币种处理取价差异**：USDT 未开启默认汇率时改查线上 USDT/CNY；TRX 未开启默认汇率时因没有可用的线上 TRX/CNY 交易对，必须阻止 TRX 下单并明确提示。两个开关均不改变商户端原有默认充值方式。
- [ ] **增加商户端 TRX 充值方式**：在“创建充值订单”中增加“TRX充值”；商户仍填写要上分的 CNY 金额，选择 TRX 后展示 TRX/CNY 汇率和预计应转 TRX 数量；上分 CNY 金额必须大于 0，最多 2 位小数。
- [ ] **锁定汇率并计算应转数量**：提交时重新校验有效汇率，保存上分 CNY 金额、充值币种 TRX、本单锁定的 TRX/CNY 汇率及应转 TRX 数量；计算公式为“应转 TRX = 上分 CNY 金额 ÷ 本单锁定汇率”，前端预览不得作为最终账务结果。
- [ ] **直接上分 CNY**：TRX 到账并满足处理条件后，按订单确认的上分 CNY 金额执行自动或人工上分；全过程不把 TRX 换算成 USDT、不生成 U 余额，重复通知或重试不得重复上分。
- [ ] **调整商户端与后台订单列表**：增加 TRX 筛选和订单展示；表头统一为“上分金额（CNY）、充值币种、应转数量、兑CNY汇率、浮动数量、浮动费率”；每行的应转数量和浮动数量必须带对应币种。
- [ ] **调整汇总、导出与历史兼容**：上分金额统一按 CNY 汇总，应转数量按 CNY、USDT、TRX 分币种汇总；导出增加充值币种、锁定汇率、应转数量并使用新表头；历史订单不按当前汇率回填或重算，现有人民币、USDT 流程保持可用。

## 测试要验

- [ ] **汇率设置**：列表同时显示 USDT/CNY、TRX/CNY，两个默认开关可独立启停；启用默认时汇率为空、非数字、0 或负数保存失败且不覆盖原值。
- [ ] **默认取价分支**：关闭 USDT 默认后，USDT 订单仍能取得线上 USDT/CNY 并创建；关闭 TRX 默认后，TRX 页面显示不可下单且提交失败；重新启用有效 TRX 默认汇率后恢复创建。
- [ ] **创建订单校验**：商户端选择 TRX 后仍输入上分 CNY 金额；金额大于 0 且不超过 2 位小数时可提交，小于等于 0、超过 2 位或使用科学计数法时被明确阻止；TRX/CNY 汇率无效时不能创建订单。
- [ ] **换算与锁价**：当“1 TRX ≈ 0.95 CNY”、上分金额为 950 CNY 时，应转数量为 1000 TRX；订单创建后修改默认汇率，原订单的汇率、应转 TRX 和上分 CNY 金额均不变，新订单使用新汇率。
- [ ] **自动与人工上分**：分别在自动上分开启、关闭条件下完成一笔 TRX 订单；两种路径均只更新一次 CNY 余额，不产生 USDT/U 中间余额，重复通知、重复点击和重试不产生重复上分。
- [ ] **列表、筛选与表头**：商户端和后台均可筛选 TRX，并正确显示上分金额（CNY）、充值币种、应转数量、兑CNY汇率和浮动数量；TRX 行的应转数量以 TRX 展示，重置后恢复全部币种。
- [ ] **汇总与导出**：上分金额按 CNY 统一汇总，应转数量按币种分别汇总；导出结果与页面查询条件、数据权限、字段名称、币种和数量一致。
- [ ] **回归与异常**：历史订单不被新汇率重算；人民币、USDT 创建、查询、上分和导出正常；查询、保存、创建或导出失败时有明确反馈并保留必要操作条件。
