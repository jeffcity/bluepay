# 美人桥钱包一期接入说明

## 本期范围

- 仅 USDT 充值、余额、充值订单和流水；自动到账异常时支持后台人工确认入账、取消。
- **充值不收手续费，实际收到多少 USDT 就入账多少。** 不新增全局或商户钱包充值费配置，不影响其他业务费率。
- TRX 充值、USDT 兑换 TRX、汇率配置及能量租赁延期；旧演示数据保留，不作为一期入口。

## 复用现有收款链路

1. 创建订单时复用现有美人桥地址获取、分配代码，保存本单地址、网络及分配标识。真实方法和字段由开发核对，不在 Demo 中另定接口。
2. 本单地址文字、复制结果、二维码须一致；刷新或重开详情读取已分配结果，不重新分配、不串用其他订单地址。
3. 复用现有查链、币种／网络校验、确认、交易去重、异常与通知重试；不另建地址池或监听服务。地址有效期、少付／多付／分次到账与取消后到账的完成条件需核对原规则并经产品确认。
4. 确认实际收款后，全额增加商户 USDT 余额，写成功订单和一笔入账流水；不扣费、不换算 CNY。创建订单本身不改余额。
5. 自动与人工确认共用入账逻辑；状态、余额、流水同一事务完成，重复通知和并发操作只允许一个有效结果。

## 运营兜底与权限

- 仅待收款可手动确认或取消。确认填写收款核验说明，取消填写原因；保存操作人、方式、时间及证据关联。成功／取消后不重复处理。
- 人工确认须实际核实收款，按实际收款全额入账，不绕过服务端权限、状态及去重校验。失败不部分改余额或订单。
- 取消不记资金流水；取消后真实收款须保留核查记录，后续按最终确认的异常规则处理，不能直接丢弃。
- 同步钱包菜单、查询／详情、创建充值、手动确认及取消的按钮权限、接口鉴权和目标角色授权；商户仅看自己，后台限定美人桥业务。
- 服务端只接受本期 USDT 操作，拒绝 TRX 充值或兑换；隐藏入口不代替服务端限制。

## Demo 与真实服务的边界

- 页面源：`src/pages/美人桥商户钱包/美人桥商户钱包-demo.html`。`createTopup`创建零手续费USDT单，`collectionInfo`展示本单收款信息，`receiveTopup`和`manualConfirmTopup`模拟全额入账。
- Demo地址、二维码和收款通知均为演示，不发起真实转账；真实地址分配、到账监听、服务端事务及权限须接入现有后端。
- 旧待收款演示单显示全额，并在确认成功后记录零费及全额入账；已完成账本不追溯改写。生产若存在旧单，迁移范围和规则需单独核定。
- 验收至少覆盖100USDT入100、无手续费字段和配置、地址三者一致、重开地址不变、重复通知不加款、人工／自动／取消竞争及权限拦截。
