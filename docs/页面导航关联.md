## 维护业务页面

1. 先从 `project.json` 的 `nav.<端>` 定位既有业务页对应的 `doc` 与 `boot`。
2. 在该页面的现行源文件上增量修改，保留既有字段、交互和币种能力。
3. 新需求只需在 `pages` 登记 BP-REQ，并把编号补到受影响导航叶子的 `req`；不得另建需求专属 Demo。
4. 只有产品真实新增导航页面或独立端时，才新增 `src/pages/...` 页面源及导航叶子。
5. 运行 `npm run check`，确认不存在未登记页面源且统一入口可达。
